# Starter manifest

## Tier definitions
- **Tier 1:** explicitly endorsed by the pre-session guide. Project skeletons, dependencies, configuration, Docker files, run instructions, a request file.
- **Tier 2:** generic plumbing any REST backend needs (error response shape, exception handler, extra tests, UI health badge). **None created in this scaffold**, by decision; to be chosen after the debrief.
- **Out of scope:** domain entities, repositories, business endpoints, LLM gateway or client, prompts, events, SSE, feature screens, authentication, Lombok, Spring AI, Flyway.

Files generated by tools (`package-lock.json`, Vite template assets) are listed because they exist in the repo.

| Path | Tier | Purpose | Delete if |
|---|---|---|---|
| `README.md` | 1 | Prerequisites, run commands, cache warm-up, config notes | Never; edit it |
| `STARTER_MANIFEST.md` | 1 | This inventory | You no longer need the audit trail |
| `.gitignore` | 1 | Ignores build output, node_modules, IDE files, `.env` | Never |
| `.env.example` | 1 | Documents `LLM_API_KEY` without a value | You pass the key another way |
